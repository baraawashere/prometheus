Prometheus

Type any topic. PROMETHEUS automatically writes a script, generates 
images, creates a voiceover, and assembles it all into a video.


How It Works
1. You type a topic (e.g. "Explain black holes")
2. Claude writes a structured script with sections
3. FLUX generates an image for each section
4. Edge-TTS reads each section as a voiceover
5. MoviePy assembles everything into a final MP4
6. You download the video directly from the app

Features
- Full Text → Image → Voice → Video pipeline
- Regenerate individual sections (script or image)
- Background music royalty-free or upload your own MP3
- Word count display per section
- Settings tab tone, image style, voice picker
- Download button for the final video
